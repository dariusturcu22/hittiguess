Every count uses the same flat coin, 52px, thick dark border, hard offset shadow, a stacked $ mark. Zero tokens is an empty dashed ring, never a blank space, so it still reads as "your token spot" rather than missing UI. From one token on it's a loose scatter, each coin at its own small rotation, piling up toward the top-right as the count grows, never a neat grid and never sorted into a row. This is the same coin used for the corner "Your tokens" pile and for a staked bet sitting in a timeline gap, just placed differently depending on context.
