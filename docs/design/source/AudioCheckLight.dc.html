Audio check, before the game starts
Shown after the host presses Start game, before the first turn. Every player who can DJ shares their audio and passes a sound test.
How the audio test works. The audio check reads the shared stream's audio track and watches its level. The test passes once the level stays above a small threshold for about half a second, so a share that exists but carries no sound never passes. The share leaves out the game tab's own audio, so a test tone from the game page would never reach the meter. The test therefore asks for any sound on the computer, and offers a link to open YouTube in a new tab. Each DJ shares once on this screen and keeps that share running until the game ends, so there is no sharing per turn. A share with no audio track at all fails at once, with the help text about ticking Share system audio, without waiting for the meter.
Rules shown here. Fixed mode: only the chosen DJ shares and passes the test, everyone else waits. The fixed DJ plays the songs and does not take guessing turns. Rotating mode: every player must be able to share and pass the test, because everyone takes turns as DJ. A player whose browser cannot share blocks the start, and the host can switch to a fixed DJ instead. When nobody can share, the screen says so and there is no way to start. Start game stays disabled until every required player has a check mark. A failed or silent share offers Share again, which reopens the picker so the player can choose a different screen.
